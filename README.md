# Ruletática

App de retos de historia de Costa Rica. Girás un tema, investigás contra reloj y exponés en un minuto.

## Cómo abrirla

1. Instalá [Node.js](https://nodejs.org/) (versión 18 o superior).
2. En esta carpeta, abrí una terminal y ejecutá:

```bash
npm install
npm run dev
```

3. En el navegador, entrá a [http://localhost:3000](http://localhost:3000).

## Controles

- **Girar tema** o la **barra espaciadora**: elige un tema con el ticker.
- **Modo Reto**: 15 min de investigación + 1 min de exposición.
- **Modo Express**: 3 min + 1 min.
- **Buscar en Google**: abre la búsqueda exacta del título.
- Durante la investigación: pausa, notas rápidas y saltar fase.
